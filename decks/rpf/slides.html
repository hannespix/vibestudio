02 / das kontextfenster

Der Chat vergisst.

Das Kontextfenster ist begrenzt. Ist es voll, fasst die KI zusammen, Details können verloren gehen. Das Repo behält sie.

45 Sekunden. Stichworte: Das Kontextfenster ist das Arbeitsgedächtnis der KI in einer Sitzung: Anweisungen, Gesprächsverlauf, gelesene Dateien. Es ist begrenzt. Wird es voll, räumt Claude Code automatisch auf: erst ältere Werkzeugausgaben, dann fasst es das Gespräch zusammen. Anfragen und wichtige Codestellen bleiben, frühe Detailanweisungen können verloren gehen. Deshalb gehört alles Wichtige als Datei ins Repo: Code, README mit Ziel und Einstieg, kurze Notizen zu Entscheidungen und nächsten Schritten. Nach dem Verdichten oder in einer neuen Sitzung liest die KI diese Dateien neu ein. Vorteile: nichts Wichtiges hängt am Chat, jeder Stand ist versioniert, und Kolleginnen, Kollegen oder andere Werkzeuge finden alles am selben Ort. Git vergrößert das Kontextfenster nicht; die Dateien müssen gepflegt und gelesen werden. Quellen: https://code.claude.com/docs/en/how-claude-code-works ; https://code.claude.com/docs/en/memory . Stand: 28.09.2026.

04 / was github dazugibt

GitHub arbeitet mit.

Automatisch.

Tests und Veröffentlichung laufen bei jeder Änderung.

Sicher.

Nur geprüfte Änderungen. Klare Rechte. Keine Passwörter im Code.

Versioniert.

Jeder Stand bleibt. Alles lässt sich zurückholen.

Beispiel: Diese Präsentation wird bei jeder Änderung automatisch getestet und veröffentlicht.

40 Sekunden. Stichworte: Automatisch: GitHub Actions starten bei jeder Änderung Tests und veröffentlichen das Ergebnis, bei dieser Präsentation genauso. Sicher: Änderungen kommen über einen Pull Request und werden erst nach Prüfung übernommen; Rechte legen fest, wer was darf; Zugangsdaten gehören nie ins Repo, dafür gibt es geschützte Geheimnisse (Secrets). Versioniert: Jeder Stand ist gesichert und lässt sich vergleichen und zurückholen; das gilt für Dateien, nicht automatisch für Datenbankinhalte oder externe Aktionen. Im LVM leistet ein internes GitLab dasselbe. Quellen: https://docs.github.com/en/actions ; https://docs.github.com/en/actions/concepts/security/secrets ; https://docs.github.com/en/get-started/using-git/about-git ; https://docs.gitlab.com/user/project/merge_requests/ . Stand: 28.09.2026.
